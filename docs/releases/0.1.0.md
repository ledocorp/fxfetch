# fxfetch 0.1.0

**Date:** 12 August 2026  
**Tag:** `v0.1.0`  
**Requires:** [fxlang](https://github.com/ledocorp/fxlang) **v0.9.6+** with **`--cli`** (Win + Linux x86_64)

## Highlights

- First public release of **fxfetch** — HTTPS GET under NetCap  
- Dual-path bins: `fxfetch` (emit-C) and `fxfetch-ir` (IR)  
- Required `--allow-host` and `--ca`; no ambient network trust  
- No author-written `host/*.c` — rebuild with `fx build fxfetch_lib.fx … --cli`  

## Install

Download `fxfetch-0.1.0-windows-x86_64.zip` or `fxfetch-0.1.0-linux-x86_64.tar.gz` from this release.

## Notes

- Needs an fx package that ships `--cli` + `host/cap` (including TLS dial) at 0.9.6+.  
- Links Mbed TLS 2.28.x (Apache-2.0). See NOTICE.  
- v1 is GET-only (no POST, cookies, or redirects).  
- macOS prebuilts are not claimed.
